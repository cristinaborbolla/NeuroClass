Alzheimer staging
through deep learning

NeuroClass uses a convolutional neural network trained on brain MRI images to automatically classify Alzheimer's disease into four diagnostic stages, supporting early detection and longitudinal follow-up.

🧠

MRI-based classification

Analyses axial brain MRI slices and classifies them into four Alzheimer’s stages in under a second.

📊

Probability distribution

Returns the full softmax probability vector for all four classes, providing clinicians with a transparent view of model confidence.

🎮

Cognitive games

Patients can access interactive cognitive exercises focused on memory, attention and orientation, with automatic performance tracking.

⚙️

Clinical monitoring system

Patient results and cognitive evolution are securely stored, enabling personalised recommendations and continuous follow-up.

Alzheimer's disease staging

Alzheimer's disease progresses through identifiable stages with characteristic changes in brain structure and cognitive function. Understanding these stages is key to early diagnosis and intervention.

The four diagnostic stages used in this classifier

1
Non-Demented No impairment ▼

No significant cognitive impairment is present. Brain structure appears within expected ranges, with cortical thickness and ventricular volume showing no pathological signs.

Normal memory function
Intact daily activities
No cortical atrophy
Normal ventricular size
2
Very Mild Demented Very mild decline ▼

Subtle cognitive changes begin to appear, primarily affecting memory for recent events. These changes may be attributed to normal ageing, making early detection challenging.

Occasional forgetfulness
Mostly independent
Subtle hippocampal changes
Early monitoring advised
3
Mild Demented Mild decline ▼

Memory loss becomes noticeable and interferes with daily activities. Brain imaging typically reveals enlarged ventricles and measurable reduction in hippocampal volume.

Noticeable memory loss
Difficulty with complex tasks
Enlarged ventricles
Temporal lobe atrophy
4
Moderate Demented Moderate decline ▼

Significant cognitive decline affecting multiple domains. The patient requires assistance with daily activities. MRI shows significant diffuse cortical atrophy and substantially enlarged ventricles.

Requires daily assistance
Recognition difficulties
Significant cortical atrophy
Full care often needed

How the model works

  • Input: axial brain MRI slice (grayscale)
  • Preprocessing: CLAHE contrast enhancement
  • Resolution: 190 × 200 pixels
  • Architecture: custom CNN (Advanced-Reduced)
  • Output: softmax probabilities over 4 classes
  • Dataset: Kaggle Augmented Alzheimer MRI

Clinical disclaimer

  • This tool is a research prototype
  • Not validated for clinical use
  • Results must be reviewed by a physician
  • Do not use for self-diagnosis
  • Single-slice classification has limitations
  • Combine with full clinical assessment
